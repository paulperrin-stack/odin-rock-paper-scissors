# Rock Paper Scissors 🪨📄✂️

A browser-based Rock Paper Scissors game built with vanilla HTML, CSS, and JavaScript.

## 🎮 Live Demo

[Play it here](https://paulperrin-stack.github.io/rock-paper-scissors/)

## How to Play

1. Click **Rock**, **Paper**, or **Scissors** to make your choice
2. The computer picks randomly
3. First to **5 points** wins the match
4. A message tells you the result of each round

## Features

- Score tracking for both player and computer
- Round-by-round result messages
- Automatic win detection at 5 points
- Buttons disabled at game over

## What I Learned

- DOM manipulation with `querySelector` and `querySelectorAll`
- Attaching event listeners to multiple elements
- Using `data-*` attributes to pass values from HTML to JavaScript
- Managing game state with variables
- Separating logic into focused functions
